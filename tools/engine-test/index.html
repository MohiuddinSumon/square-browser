Engine test

Open this page once with Settings > New Web Engine off and once with it on (restart the app in between). Compare the green/red results.

1. Scripts before the page

Needs Background Playback and Ad Blocker on. New engine: both green every time. Old engine: often red (it races the page). Reload a few times.

2. Scripts in frames

Both engines should show "main page only": SquareBrowser's scripts must not run inside embedded frames.

3. Address bar on in-page navigation

Tap, then check the address bar shows ?step=N. Both engines should update it.

4. Open in app

Each should ask "Open in app?" in both engines. "Stay in browser" on a web link should load the page without asking again.

whatsapp:// link intent:// link (WhatsApp, with fallback page) market:// link Play Store web link wa.me web link (made-up number) Play Store badge (new window) file:// link (must do nothing) Link to an ad domain (must do nothing with Ad Blocker on)

5. Popups

Turn Ad Blocker off for this section (with it on, both engines block every popup). Both engines: the tapped one opens a new tab; the delayed one is blocked by the WebView's popup blocker.

6. Video

Both engines: fullscreen turns the phone to landscape with a rotate button top right, and back leaves fullscreen. With Background Playback on, start the video, then leave the app: it keeps playing and the notification controls work.

6b. Files and permissions

File upload opens Android's picker in both engines. Download: the new engine shows "Downloading …" and the file lands in Downloads. Location: both engines say no (SquareBrowser has no location permission).
